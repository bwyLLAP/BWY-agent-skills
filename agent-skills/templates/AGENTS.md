# AGENTS.md

## Project Rules

- Prefer existing project conventions over introducing new architecture.
- Keep changes narrowly scoped to the requested behavior.
- Do not rewrite unrelated code or formatting.
- Add or update tests when behavior changes.
- Before finishing, run the smallest relevant verification command and report the result.

## Frontend Rules

- Build the actual product experience first, not a marketing landing page.
- Use restrained color, clear hierarchy, and practical spacing.
- Avoid emoji-heavy UI, generic gradient decoration, and decorative cards inside cards.
- Make controls complete and usable across desktop and mobile.

## Review Rules

- Prioritize correctness, regressions, security, data loss, and missing tests.
- Lead with actionable findings and file references.
- Keep summaries short.
